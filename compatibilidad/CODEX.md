# Codex

Abrí la raíz del kit. Codex descubre `AGENTS.md` y la skill canónica en
`.agents/skills/crm-multicanal/SKILL.md`.

Pedí `configurá el CRM` y después `construí el CRM`. No hacen falta comandos: todo el
método está en la skill y se activa por lenguaje natural.

No copies la skill a una carpeta personal: mantenerla dentro del proyecto evita versiones
divergentes y permite entregar el kit completo.

Codex necesita aprobación para ejecutar comandos. Este kit los usa de verdad (`npm`,
migraciones, scripts de verificación), así que trabajá con aprobaciones activas y revisá
cada comando antes de aceptarlo. **No uses modos de aprobación automática**: varias
acciones de la Fase 8 mandan mensajes a personas reales.
